# =============================================================================
# docker-a2a-gateway — container dependency set
# =============================================================================
# This image runs the SilvaEngine Gateway exposing ONLY a2a_daemon_engine
# (native A2A protocol surface) which bridges tasks to a Hermes Agent API
# Server and/or an OpenClaw Gateway over HTTP + SSE. The route manifest is
# A2A-only (see routes.yaml), so no KGE / RFQ / MCP engine deps are pulled in.
#
# silvaengine_gateway and a2a_daemon_engine are installed --no-deps in the
# Dockerfile (their metadata lists engines / bare names not on PyPI); this
# file provides their real third-party deps and the shared SilvaEngine libs.
# Private ideabosque repos are fetched over git+ssh (the image copies a deploy
# key and trusts github.com — see Dockerfile / README).
# =============================================================================
